● Complete Track Alignment

The 3 Hackathon Pillars in One Unified System

Pillar 1: Vision + Web AI
  • MobileNetV3 Large: 1,000 real ImageNet classes with sub-second webcam inference.
  • 60% Confidence Threshold: Stops guessing wrong classes; prompts user to steady camera.
  • Google Search Engine AI: Solves blur/packaging by cross-referencing brand names on live web search.
  • Dual-Tier Segregation: Item category + Bio vs Non-bio + municipal bin color.
Pillar 2: IoT + Digital Twin
  • Multi-Sensor Telemetry: Ultrasonic (fill %), MQ-135 (methane gas), GPS, and weight load cell.
  • GIS Leaflet Virtual Twin: Live color-coded bin health: Green, Yellow, and Red.
  • What-If Simulation Engine: Visually models: "What if collection is skipped for 2 days?".
  • Dynamic Route Optimizer: Trucks visit only full bins, saving up to 38% fuel.
Pillar 3: Generative AI
  • Autonomous Dispatch Advisory: LLM analyzes telemetry to alert: "Bin 7 will overflow in 2.8h, reroute truck".
  • Multilingual Citizen Assistant: Natural language queries in English, Hindi, and Kannada.
  • Automated Daily Reports: One-click executive summaries for city corporators.
  • Zero Fake Data: Real SQLite database, user reviews, leaderboard points, and photo reports.
● Deep Dive — Pillar 1

Computer Vision + Google Search Engine AI

Solving Hackathon Object Misclassification

Traditional models fail when exposed to real-world commercial packaging, lighting shifts, or brand wrappers, defaulting to "Plastic" for every object.

1. Pretrained MobileNetV3 (1,000 Classes) Fast, lightweight transfer learning model trained on rich real-world item variations.
2. 60% Confidence Guardrail If visual certainty is < 60%, the UI displays "Not sure, please try again" instead of hallucinating.
3. Google Search Engine Knowledge AI Users can search any brand name or use 1-tap chips to pull live web citations and scientific disposal properties.

● Deep Dive — Pillar 2

IoT Sensor Mesh & Real-Time Telemetry

HC-SR04 Ultrasonic

Fill Level (0–100%)

Measures garbage height delta. Automatically trips critical state when fill level ≥ 90%.

MQ-135 Gas Sensor

Methane & Odor (ppm)

Detects anaerobic decomposition gases. Preempts foul odors and landfill fire hazards.

Load Cell Sensor

Payload Weight (kg)

Measures physical payload weight to prevent bin structural failure and track daily municipal tonnage.

NEO-6M GPS

Geo-Coordinates

Broadcasts exact latitude/longitude for dynamic vehicle routing and nearest-bin discovery.

● Deep Dive — Pillar 3

GIS Digital Twin & What-If Simulation Engine

Interactive GIS Virtual Twin

  • • Real-time Leaflet GIS virtual replica of all city smart bins & collection vehicles.
  • • 3-Color Visual Status:
  • 🟢 Green (0–50%): Clean
  • 🟡 Yellow (50–89%): Near capacity
  • 🔴 Red (≥ 90% / Gas alert): Urgent
  • • Interactive popups expose live fill %, methane ppm, temperature, and payload weight.

What-If Simulation Engine

  • • "What happens if we skip collection for 2 days?"
  • • Models non-linear municipal waste accumulation and identifies cascading overflow zones.
  • • Predicts stench propagation before citizens file complaints.
  • • Empowers city planners to conduct risk stress-testing and budget contingency fleets.

Dynamic Route Optimization

  • • Computes greedy shortest path for municipal collection trucks.
  • • Eliminates empty bin stops: Visits only bins marked Yellow or Red.
  • • Saves up to 38% diesel fuel: Drastically slashes municipal fleet operational expenditure.
  • • Outputs turnaround time, total distance, and carbon emissions averted.
